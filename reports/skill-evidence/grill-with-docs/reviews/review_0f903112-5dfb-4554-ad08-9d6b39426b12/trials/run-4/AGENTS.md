# Fixture authority

Read authority before acting:

1. `docs/principles.md`
2. accepted ADRs and `docs/adr/README.md`
3. `architecture-review.md`
4. the source files named by surviving candidates

Higher authority defeats a review candidate. Do not amend principles. Accepted ADRs are changed only by explicit amendment or a new accepted decision whose scope does not silently replace them. Execute only reversible candidates that survive adjudication. Keep the five-candidate review order.
