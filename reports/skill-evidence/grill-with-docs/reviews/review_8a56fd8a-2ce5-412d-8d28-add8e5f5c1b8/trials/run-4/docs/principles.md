# Documentation authority

Protocol-level terms remain authoritative in `docs/protocol-glossary.md`. The project glossary may name a project-layer concept but must not restate an upstream definition.

An accepted ADR remains authoritative until explicitly superseded. Clarifying the shape or required content of the artifact that ADR already governs is an amendment to that ADR, not a new architectural decision.

Dependent workflow prose must agree with the glossary and accepted ADRs.
