There is one decision branch: whether the heading should name a human choice or a reported result.

Which heading should the note use?

- `Decision` (Recommended) — best when the note records a human choice. It makes the note’s authority explicit, but would be misleading if the content is generated mechanically.
- `Outcome` — best when the note reports a mechanical result. It avoids implying human judgment, but is less precise if a person actually made the choice.
