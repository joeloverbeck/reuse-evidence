## Binding constraint and witness

Binding constraint: the operator must resume after substantial premise work and cross at least two governed phase boundaries in a multi-item or multi-phase run. A fresh, tiny one-question task does not express the recorded condition.

The reproduction trial has three fixed runs. Its witness reads **expressed** only when the retained transcript or artifacts show both:

1. all twelve numbered checkpoint facts in that run were consumed or dispositioned; and
2. the executor crossed the named question, mutation, handoff, or delivery boundary.

It reads **unexpressed** if either condition is absent. An unexpressed first run stops the reproduction trial. An unexpressed candidate-arm run is replaced once with the same frozen packet and a fresh executor; it is never discounted.

No reliable per-launch incidence estimate is supported: the packet records several long runs and several clean outcomes but no denominator tied to the same run condition. The reproduction count is therefore the three-run floor.

## Executor and evaluator independence

- Every executor receives one neutral arm directory, one raw task, and its raw input artifact in a fresh agent session with minimal task-local context.
- Executors are barred from `reports/skill-evidence/`, the review diagnosis, the other arm, expected winners, and prior outputs.
- Neutral arm names are fixed before execution. The administrator retains their mapping; evaluators receive randomized response labels and no arm mapping.
- Executors may write only to their assigned `/tmp` trial directory and may not access the network or mutate the repository.
- Evaluators judge raw outputs against the frozen rubrics. They receive neither the diagnosis nor candidate bytes.

- The binding-condition witness is expressed.
- Every boundary obligation applicable to the run occurs before the boundary it governs.
- The delivered decision or artifact contains every numbered requirement and no forbidden action.
- A question is answerable in one user turn, recommendation-first, and contains only one independent fork.

## Acceptance rule

A candidate can land only if the unchanged arm reproduces the mechanism with the witness expressed, the candidate materially improves the reproduction outcomes, it is noninferior on Trials 2-5, it introduces no material or severe regression, affected deterministic checks pass, and any runtime growth is necessary and minimal. A compliance-only difference without a demonstrated outcome deficit cannot adjudicate the trigger events and cannot justify landing.
