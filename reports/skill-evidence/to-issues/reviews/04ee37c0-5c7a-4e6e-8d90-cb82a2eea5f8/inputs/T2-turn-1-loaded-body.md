## Goal

Allow a maintainer to verify a bounded set of accepted results and record each disposition without changing unrelated cases.

## User stories

1. Select a bounded case set.
2. Read each accepted decision.
3. Attach evidence per verification condition.
4. Record met and not-met results.
5. Park a case with a named reason.
6. Close only complete cases.
7. Resume a partially verified batch.
8. Leave unrelated cases untouched.
