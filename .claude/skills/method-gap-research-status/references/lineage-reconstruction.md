# Lineage Reconstruction

Use these rules only to recover the target-specific state a read-only family
selector needs. They do not authorize research, adjudicate a recommendation, or
expand the census into a semantic audit.

## Discover target-specific lineage

Start with the inventory-provided candidates and bounded excerpts. When they
show that lineage may be incomplete, search by the target's exact name, path,
prior names found in those artifacts, and stable report markers. Keep every
discovery search inside the repository root resolved from the target; the
caller's working directory is not evidence that another repository owns it.

Search current report, research, decision, and archive conventions, plus version
control or the issue tracker when available. Read only candidates that could
alter the target's lineage state. Distinguish current authority from archived
evidence. A generic commissioning framework is not target lineage unless it
identifies the target or records a target-specific disposition.

## Classify each prior line

Place each target-specific research line in exactly one state:

1. brief authored, research not returned;
2. report returned, not yet adjudicated;
3. recommendation adopted, with its landing identity;
4. recommendation rejected, with its reason;
5. recommendation deferred, with its concrete trigger and whether it fired; or
6. superseded, with the replacing line named.

`None found` is a recoverable state: it means the later target census would be
the first audit, not that an audit is due.

## Distinguish overlap from interval evidence

A target-specific method-gap brief awaiting research or a returned report
awaiting adjudication is overlapping work. Do not recommend a duplicate line.

Active target execution or editing is not overlap by itself. Treat it as
interval evidence, and require only that a coherent method-bearing baseline can
be frozen. Downstream adjudication, calibration, or repair is likewise not
overlap by itself; map it as existing feedback machinery and interval evidence.
If either is changing too rapidly to freeze a trustworthy baseline, the coherent
baseline gate fails. Unrelated repository work has no lineage or cadence effect.
